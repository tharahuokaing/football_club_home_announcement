🌐 Technical Architecture

The site uses a clean, single-page announcement architecture supported by shared style and script files:

huokaingthara_football_club_home_announcement/
├── index.html     # Main Home & Announcement page markup
├── style.css      # Dark cyberpunk athletic styling (#0f172a, #00f2fe accents)
├── script.js      # Dynamic English (EN) and Khmer (KH) language switcher
└── README.md      # Repository documentation


Features:

Instant Language Toggle: Seamless switching between English (.en-text) and Khmer (.kh-text).

Responsive Dark Theme: Styled using a modern slate dark theme #0f172a with high-contrast cyan #00f2fe highlights for maximum visibility on mobile and desktop.
